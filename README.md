# yask's Command Center

AI-powered ServiceNow Operations Dashboard built for Major Incident visibility, executive operational intelligence, and real-time incident monitoring using Service Portal and AngularJS.

---

# Overview

Yask's Command Center is a modern ServiceNow Service Portal dashboard designed to simulate a real enterprise Operations Command Center (NOC).

The project provides:

- Real-time operational visibility
- Major Incident monitoring
- Executive impact analysis
- Interactive incident drilldowns
- SLA risk awareness
- Business service visibility
- Analyst and Executive operational views

The dashboard was designed to improve operational awareness and incident response workflows while demonstrating advanced ServiceNow UI engineering concepts.

# Architecture

The project follows Service Portal widget architecture principles:

| Layer | Responsibility |
|------|------|
| HTML Template | Dashboard UI |
| Client Controller | AngularJS interactions |
| Server Script | GlideRecord data retrieval |
| CSS | Dashboard styling and responsiveness |

# Performance Optimization

The dashboard uses a lightweight auto-refresh mechanism to ensure:

- Minimal server overhead
- Reduced latency
- Better responsiveness
- Scalable dashboard behavior

Data refresh occurs periodically without requiring full page reloads.
